# Style: Editorial

Review text is the hero, set like a magazine quote. Calm, spacious, serif-friendly. Close to Loox's dynamic carousel.

| Part | Editorial |
|---|---|
| Layout | 1 to 2 large cards per view on desktop, 1 card with the next one peeking (about 85% width) on phones |
| Text | Review text 20 to 24px, line height 1.5, clamped to 6 lines (4 on phones); heading font for the text when the store has a serif |
| Quote mark | Oversized opening quote in the accent color above the text (design-rules.md, lx-quote) |
| Photo | Beside the text on desktop (40% width), above it on phones; one shape, 4:5 |
| Cards | Tinted surface (8% accent), radius 24px, no shadow, padding 32px desktop, 20px phones |
| Stars | Small, under the quote; name and date in a quiet line at the bottom |
| Motion | lx-rise entrance and lx-quote; nothing on loop |
