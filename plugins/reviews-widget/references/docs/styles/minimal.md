# Style: Minimal

Clean and quiet. The widget blends with the theme and lets the content speak.

| Part | Minimal |
|---|---|
| Layout | Grid of equal cards: 3 to 4 columns on desktop, 2 columns on phones (`repeat(2, minmax(0, 1fr))`, more columns through `@container`, phone.md) |
| Text | Review text 15 to 16px, clamped to 4 lines; body font of the store |
| Photo | Small square photo on top, radius equal to the card radius |
| Cards | Page background with a 1px hairline border (text color at 12%), radius 8 to 12px, no shadow, padding 16px |
| Stars | Store star color, small, above the text |
| Header | One line: average stars, count, write button aligned to the end |
| Motion | lx-lift on hover only (desktop); no entrance animation |
