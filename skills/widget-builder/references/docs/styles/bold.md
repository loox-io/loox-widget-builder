# Style: Bold

Loud and confident: brand color blocks, big stars, playful motion. Fits brands with strong, colorful themes.

| Part | Bold |
|---|---|
| Layout | Header as a full-width accent block (accent background, white text) above a grid or row of cards |
| Header | Average shown big: stars 32px and up, count in heavy weight, write button as a pill in the button color |
| Cards | Solid accent-tinted surface (15 to 20% accent) or alternating accent and light cards; radius 20 to 32px |
| Text | Review text 18 to 20px in the text color; size and color carry the emphasis |
| Stars | Large (20px+) in the store star color; lx-star-pop on hover |
| Motion | lx-rise with stagger, lx-lift, lx-star-pop; one playful accent such as a pulsing write button (components/header-write-button.md) |
