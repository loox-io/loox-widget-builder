# lxrw-empty-state

"Be the first to write a review" on a product with no reviews. The link opens the review form.

Kind: display part. Goes inside: `<loox-reviews-widget>`.

## Style

| Token or hook | Changes |
|---|---|
| `--loox-lxrw-u-header-text-color` | Text color |
| `::part(empty)` | The message box: font, spacing |

## Admin settings that affect it

Draws nothing when the store hides the write-a-review button. The text follows the store's language.
